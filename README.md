# UNP_VAC_PROJECT_AURA_THERAPEUTICS_PHARMA_DISTRIBUTION_ANALYTICS_USING_MS_EXCEL

Pharmaceutical Distribution Data Analytics & AI-Based Business Analysis

In Collaboration with UNP Education

Project by: Naveen Yadav
Course: B.Com (Computers) – 2A1

I am pleased to share my project on Pharmaceutical Distribution Data Analytics & AI-Based Business Analysis, completed in collaboration with UNP Education.

This project focuses on analysing pharmaceutical distribution business data using Microsoft Excel and AI-assisted data analytics techniques.

I worked with a dataset containing 7,243 records and 20 columns to understand business performance, identify meaningful patterns, analyse relationships between variables, and generate data-driven business insights.

1. Excel Work

- Data cleaning and preprocessing
- Duplicate removal and missing value treatment
- Outlier identification using the IQR method
- Descriptive statistical analysis
- Pivot tables and data visualisations
- Hypothesis testing using ANOVA, t-tests and Z-tests
- Correlation matrix and relationship analysis
- Simple Linear Regression
- Multiple Linear Regression
- Business findings and interpretation

2. AI-Based Work

- Company profile and business objectives
- Data dictionary and dataset understanding
- Data preprocessing and statistical analysis
- Data visualisation and exploratory data analysis
- Statistical hypothesis testing
- Correlation and regression analysis
- Final business summary and insights

3. Tools & Techniques

Microsoft Excel | Artificial Intelligence | Business Statistics | Data Analytics | Hypothesis Testing | Correlation | Regression Analysis

4. Project Objective

The main objective of this project was to develop practical knowledge of Microsoft Excel and AI-based data analytics while understanding how statistical techniques can support business analysis and decision-making.

This project helped me gain practical exposure to data handling, statistical methods, visualisation, and interpreting business information.
